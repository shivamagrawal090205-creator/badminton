# 🏸 Badminton Scoreboard

A simple, interactive **Badminton Scoreboard** built with HTML, CSS, and JavaScript.  
This project allows players to enter team names, track points, manage sets, and display the match winner in a clean and modern interface.

---

## ✨ Features
- 🎮 Enter custom team names before starting a match
- 📊 Real-time score tracking for both teams
- 🏆 Automatic set and match winner detection (Best of 3 sets)
- 🔄 Restart option to reset the game and start fresh
- 🎨 Modern UI with gradient background, blur effects, and responsive design
